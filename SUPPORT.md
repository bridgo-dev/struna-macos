# Help and support

Answers to setup, playback, library and license questions are in the [Struna user guide](https://docs.strunaplayer.com/). For private help, see [Troubleshooting and support](https://docs.strunaplayer.com/troubleshooting/).

## Report a bug

[Open an issue](https://github.com/bridgo-dev/struna-macos/issues/new/choose) with your Struna version (**Settings → About**), macOS version and steps to reproduce.

Issues are public. Never include license keys, confirmation codes, purchase emails, private file paths or support logs; send those privately as described in [Send a support log](https://docs.strunaplayer.com/troubleshooting/send-a-support-log/). Report security issues privately the same way.
